## Basis and scheduling

Source: CSC103_PF_Syllabus_V3.1.pdf in the parent folder. The course has 4(3,1) credit hours, 3 lecture hours and 3 lab hours per week, with no prerequisite. These decks use Java, as established by the supplied textbooks and topics.

Planning assumption: 32 sessions of approximately 90 minutes, arranged as two sessions per week over 16 weeks. This provides 48 timetable hours including the two midterm slots. The outline allocates slots 17–18 to the midterm, so those decks are supplementary concept-review and practice materials. Use them before or after the examination as the timetable permits. They do not replace an official examination. The final examination is separate from these 32 slots. Calendar dates are intentionally unset.

## Learning outcomes

| Theory CLO | Syllabus units | Outcome |
|---|---|---|
| CLO-1 | 1–2 | Explain fundamental programming concepts |
| CLO-2 | 3–5 | Employ basic programming constructs |
| CLO-3 | 6 | Handle programs using refactoring, exceptions and file I/O |
| CLO-4 | 7 | Prepare test harnesses |

Lab alignment: class exercises can support CLO-5 (implement programs using constructs) and the final integration exercise can support CLO-6 (build a medium-size application in a team). These materials supplement the separately timetabled labs.

## Suggested 90-minute teaching pattern

| Segment | Minutes |
|---|---:|
| Opening, recall and objectives | 7 |
| Four concept explanations with small examples | 28 |
| Live example and execution trace | 15 |
| Individual exercise and pair review | 20 |
| Debugging challenge and correction | 10 |
| Exit ticket and next practice | 5 |
| Questions or transition buffer | 5 |

Method-heavy lectures use part of the live-example time to inspect method definitions. Slide-note timings are suggestions and should be adjusted within this session budget. Midterm practice can use a longer uninterrupted work period.

## Assessment alignment

The supplied outline allocates theory marks as quizzes 15%, assignments 10%, midterm 25%, and terminal examination 50%. Final marks combine 75% theory and 25% lab. This plan does not change those allocations.

Suggested formative checkpoints, to be scheduled by the instructor:

- Quiz 1 / Assignment 1: after Lecture 6, aligned with CLO-1.
- Quiz 2 / Assignments 2–3: control flow and methods, followed by recursion and arrays, aligned with CLO-2.
- Quiz 3: after the exception and file-processing sequence, aligned with CLO-3.
- Quiz 4: after testing fundamentals, aligned with CLO-4.
- Assignment 4: an integrated marks-file program with a test harness, supporting CLO-3 and CLO-4.

The outline's assessment mapping lists CLO-3 under the midterm even though unit 6 appears after the midterm in its topic sequence. Confirm the official assessment blueprint rather than moving unannounced material into the midterm. The workshop rubric in Lecture 18 is formative and is not an official marking scheme.

## Detailed preparation

### Lecture 1: Computer programming

Objectives: Explain how a program solves a problem; Describe structured, object-oriented and functional approaches; Write and trace a finite algorithm.

Concepts: Programs and algorithms; Input, processing and output; Programming paradigms; Problem-solving workflow.

Class exercise: Write pseudocode for converting hours and minutes into total minutes. Trace 2 hours 35 minutes and 0 hours 0 minutes.

After-class practice: Write an algorithm for a rectangle perimeter. Give normal, zero-size and invalid-input examples.

### Lecture 2: Source files and execution

Objectives: Create and compile a Java source file; Explain the Java execution pipeline; Classify syntax, runtime and logic errors.

Concepts: A first Java source file; Compilation and execution; Three error categories; Files and working directories.

Class exercise: Create Welcome.java. Print your name and the result of 9 * 4 on separate lines. Compile and execute it.

After-class practice: Create one example of each error category. Record the error message or wrong result and its correction.

### Lecture 3: Java syntax and program style

Objectives: Distinguish tokens, identifiers and reserved words; Explain syntax versus meaning; Apply consistent names, indentation and comments.

Concepts: Tokens and special symbols; Identifiers and reserved words; Comments and documentation; Syntax, semantics and style.

Class exercise: Rewrite: int a=6;int b=4;System.out.println(2*(a+b)); Use names, spacing and a useful comment.

After-class practice: Format your previous program. Add one purpose comment and explain why each variable name is meaningful.

### Lecture 4: Variables and console input

Objectives: Declare and initialise variables and constants; Read numeric and character input; Trace assignment as a change of stored value.

Concepts: Variables and initialisation; Assignment copies a value; Scanner input; Reading one character.

Class exercise: Read a quantity and price using Scanner. Print their product. Then read a one-letter category. Use quantity 3, price 12.5, category A.

After-class practice: Read a rectangle length and width. Print area and perimeter. State the units and allowed input range.

### Lecture 5: Types and arithmetic expressions

Objectives: Choose suitable primitive types; Evaluate precedence and integer division; Use casts and conversions deliberately.

Concepts: Primitive data types; Division and remainder; Precedence and grouping; Conversions and numeric limits.

Class exercise: Convert 3672 seconds to hours, minutes and seconds using / and %.

After-class practice: Write a temperature converter. Test 0 and 100 Celsius. Explain why 9 / 5 gives the wrong conversion factor.

### Lecture 6: Updates and formatted output

Objectives: Trace prefix and postfix updates; Distinguish print, println and printf; Format a readable numeric report.

Concepts: Increment and decrement; Compound assignment; Output methods; Format specifiers.

Class exercise: Print a two-column receipt for Pen 25.5 and Book 120.0. Use aligned names and two decimal places.

After-class practice: Create a marks report showing a name, integer marks and percentage to one decimal place.

### Lecture 7: Boolean expressions

Objectives: Construct relational and logical conditions; Evaluate Boolean expressions; Choose explicit grouping for compound rules.

Concepts: Relational operators; Logical combinations; Intervals and precedence; Negation and boundary cases.

Class exercise: A ticket discount applies to ages below 12 or at least 60. Write the condition and test ages 11, 12, 59 and 60.

After-class practice: Write a library eligibility condition from two age and membership rules of your choice. Supply a truth table.

### Lecture 8: Selection with if and else

Objectives: Implement one-way and two-way selection; Build an ordered multi-branch decision; Test boundaries and nested conditions.

Concepts: The if statement; Two-way selection; Multiple selections; Nesting and compound statements.

Class exercise: Classify an integer as negative, zero or positive. Draw a decision outline, then write an if-else chain.

After-class practice: Write a shipping-charge decision for three weight ranges. State your rules and test each boundary.

### Lecture 9: Short-circuiting and switch

Objectives: Use short-circuit guards safely; Choose a conditional expression; Implement a classic switch statement.

Concepts: Short-circuit evaluation; Conditional operator; Classic switch selection; Choice of selection structure.

Class exercise: Write a menu mapping 1 to Add, 2 to Remove and every other integer to Invalid. Test 1, 2 and 9.

After-class practice: Create a four-option calculator using switch. Handle an invalid option and guard integer division by zero.

### Lecture 10: While loops

Objectives: Design terminating while loops; Use counter, sentinel and flag control; Trace state across iterations.

Concepts: The while structure; Counter-controlled repetition; Sentinel-controlled repetition; Flag-controlled repetition.

Class exercise: Design a sentinel loop for marks ending at -1. Print the count and average, or No data when the sentinel arrives first.

After-class practice: Use while to compute the digit sum of a nonnegative integer. Test 0, 7 and 204.

### Lecture 11: For and do-while loops

Objectives: Select for, while or do-while appropriately; Explain break and continue; Trace nested iteration.

Concepts: The for loop; The do-while loop; Break and continue; Nested loops.

Class exercise: Print a 3 by 4 rectangle of # characters using nested loops. Explain how many times the inner body runs.

After-class practice: Print a multiplication table for 1 through 5. Use formatted output and nested loops.

### Lecture 12: References and string input

Objectives: Distinguish values from references; Explain aliasing and null; Read tokens and complete lines.

Concepts: Primitive and reference variables; Objects and null; String values are immutable; Token input and line input.

Class exercise: Read a student age from one line and full name from the next. Explain why next() is insufficient for a name containing spaces.

After-class practice: Build a profile input program with an integer ID and a full name on separate lines. Test a name with two spaces.

### Lecture 13: String processing

Objectives: Use common String methods; Compare text content and extract substrings; Convert numeric text and numeric values.

Concepts: Length and character access; Content comparison; Substrings and searching; Numbers and text.

Class exercise: For a nonempty email-like string with one @, extract the username and domain. Test ali@campus.edu.

After-class practice: Read an item code shaped like BOOK-250. Extract the category and price, then print the price plus 10.

### Lecture 14: Built-in and instance methods

Objectives: Distinguish static and instance method calls; Explain the conventional main method; Use Math and Character APIs.

Concepts: Methods as named operations; Static and instance calls; The main entry point; Math and Character.

Class exercise: Given x=-8 and y=5, print the larger absolute value using Math methods. Test whether character 7 is a digit.

After-class practice: Use Math methods to calculate the hypotenuse for 6 and 8. Read the signatures of every method used.

### Lecture 15: User-defined methods

Objectives: Define and call reusable methods; Choose parameters and return types; Separate computation from console output.

Concepts: A method definition; Calls and returned values; Void methods; Method contracts.

Class exercise: Define static double average(int a, int b). Call it with 60 and 81 and print the result.

After-class practice: Write isEven(int n) returning boolean. Demonstrate calls for -2, 0, 3 and 8.

### Lecture 16: Parameters, stack and scope

Objectives: Explain pass-by-value and stack frames; Resolve overloaded calls; Identify local and block scope.

Concepts: Pass-by-value; Call stack and activation records; Method overloading; Variable scope.

Class exercise: Trace main with x=4 calling addOne(x), storing its returned result in y. Show the caller and callee values before and after return.

After-class practice: Write overloaded max methods for two ints and three ints. Reuse the two-argument version inside the three-argument version.

### Lecture 17: Midterm concept review

Objectives: Connect concepts from the first half of the course; Trace expressions, branches and loops; Explain the cause of a programming error.

Concepts: Review scope; Expressions and assignment; Control-flow tracing; Strings and methods.

Class exercise: In pairs, design a method that returns the larger of two numbers. Use it to find the largest of three values without arrays.

After-class practice: Create a one-page revision sheet with one traced example for each topic you find difficult.

### Lecture 18: Midterm practice workshop

Objectives: Solve an integrated problem under time constraints; Justify input and boundary cases; Review solutions using an explicit rubric.

Concepts: Practice task and assumptions; Decomposition; Boundary test design; Peer-review rubric.

Class exercise: Write the full console version for a user-specified nonnegative count. Use a method isPass(int mark).

After-class practice: Revise your workshop solution and attach three tests with expected and actual results.

### Lecture 19: Recursion and backtracking

Objectives: Identify base and recursive cases; Trace recursive stack frames; Explain recursive search and backtracking.

Concepts: Base case and progress; Recursive call stack; Recursion and iteration; Backtracking search.

Class exercise: Trace factorial(4) with base case factorial(0)=1. Then write the recursive method for inputs 0..12 using int.

After-class practice: Generate all three-character binary strings recursively. Explain why there are eight results.

### Lecture 20: One-dimensional arrays

Objectives: Create arrays with fixed or runtime sizes; Traverse elements safely; Compute an aggregate and explain bounds errors.

Concepts: Array declaration and creation; Indexes and length; Array traversal; Runtime size and aggregation.

Class exercise: Find the maximum in {-4,-9,-2}. State the policy for an empty array.

After-class practice: Read five temperatures into an array. Print the mean and number above the mean.

### Lecture 21: Arrays and method arguments

Objectives: Pass and return arrays; Distinguish mutation from parameter reassignment; Use varargs and command-line arguments.

Concepts: Passing an array reference; Reassignment and returned arrays; Variable-length argument lists; Command-line arguments.

Class exercise: Write a method returning a new doubled array while leaving the supplied array unchanged. Test {2,3}.

After-class practice: Create a program that sums integer command-line arguments. Handle zero arguments explicitly.

### Lecture 22: Two-dimensional arrays

Objectives: Create and access a table of values; Traverse rows and columns; Compute row and column totals.

Concepts: Arrays of arrays; Nested traversal; Row totals; Column totals.

Class exercise: Compute the total of every element in {{2,4},{6,8}}. Then compute its main diagonal sum.

After-class practice: Represent marks for three students in two quizzes. Print each student total and each quiz average.

### Lecture 23: Ragged and multidimensional arrays

Objectives: Pass a two-dimensional array to a method; Handle ragged rows; Explain copying and additional dimensions.

Concepts: Two-dimensional parameters; Ragged arrays; Shallow and deeper copying; Additional dimensions.

Class exercise: Write a method to count all elements in a non-null ragged array with non-null rows. Test {{1},{2,3},{}}.

After-class practice: Write a method that makes an independent copy of a ragged int[][] with non-null rows. Demonstrate that mutation of the copy leaves the original unchanged.

### Lecture 24: Exception handling

Objectives: Explain propagation and the exception hierarchy; Use try, throw and catch; Distinguish checked and unchecked exceptions.

Concepts: Exceptional control flow; Exception hierarchy; Checked and unchecked exceptions; Throwing and catching.

Class exercise: Define validateMark(int marks) that throws IllegalArgumentException outside 0..100. Test -1, 0, 100 and 101.

After-class practice: Read one integer and report malformed input using a specific catch. Keep parsing and range validation distinguishable.

### Lecture 25: Cleanup and exception propagation

Objectives: Trace nested handlers and finally; Rethrow or translate an exception; Preserve the cause of a failure.

Concepts: Propagation across calls; The finally clause; Rethrowing an exception; Chained exceptions.

Class exercise: Trace a try body that prints A and throws, a matching catch that prints B, and a finally block that prints C. What if the catch rethrows?

After-class practice: Wrap a numeric parsing failure with the input-field name and original cause. Show both messages.

### Lecture 26: Programming environments and debugging

Objectives: Use breakpoints and variable inspection; Distinguish debugging from refactoring; Refactor while preserving observable behaviour.

Concepts: A modern programming environment; Debugger operations; Refactoring; A repeatable debugging process.

Class exercise: Extract the demonstrated maximum calculation into max(int[] values). Specify empty-input behaviour and test negative-only data.

After-class practice: Record one debugging session: failing input, hypothesis, observed variable values, correction and regression test.

### Lecture 27: Library components and APIs

Objectives: Read an API signature and contract; Use library methods without guessing side effects; Choose and verify a suitable component.

Concepts: API contracts; Imports and qualification; Array utilities; Searching with a precondition.

Class exercise: Sort {9,1,4} without changing the original. Search the sorted result for 4 and explain the index.

After-class practice: Read documentation for Arrays.equals and Arrays.copyOf. Explain their signatures and demonstrate each with a short program.

### Lecture 28: Files and streams

Objectives: Distinguish files, paths and streams; Inspect file metadata; Resolve relative paths against a working directory.

Concepts: Files and paths; The File class; Byte and character streams; File operations and failures.

Class exercise: Create a File object for data/marks.txt. Display its absolute path, existence and whether it is a regular file. Explain environment-dependent output.

After-class practice: Inspect a dedicated practice file and a directory using File methods. Record differences without deleting either.

### Lecture 29: Reading and writing text files

Objectives: Write text with PrintWriter; Read data with Scanner; Use try-with-resources and explicit encoding.

Concepts: PrintWriter output; Scanner file input; Try-with-resources; A file-processing contract.

Class exercise: Read a file of integer marks and reject the first malformed token. Print No data for an empty file, otherwise the average.

After-class practice: Write three marks to a practice file and read them back. Test an empty file, malformed text and a missing input path.

### Lecture 30: Test harnesses

Objectives: Build a repeatable test harness; Choose expected results independently; Report passes and failures meaningfully.

Concepts: Tests and oracles; A simple harness; Equivalence and boundaries; Repeatability and regression.

Class exercise: Create a harness for absolute value over -5, 0 and 5. State what your method does for Integer.MIN_VALUE.

After-class practice: Build a harness with at least six cases for your average or maximum method and retain one deliberate bug demonstration.

### Lecture 31: Unit testing with JUnit

Objectives: Write a focused unit test; Use equality and exception assertions; Separate test setup, action and checks.

Concepts: A unit test; JUnit structure; Assertions for behaviour; Setup, action and checks.

Class exercise: Write a Jupiter test asserting that a mark validator rejects 101 and accepts 100.

After-class practice: Add JUnit tests for negative values, ties and invalid input to the supplied Numbers example.

### Lecture 32: Testing practice and course synthesis

Objectives: Organise parameterised and regression tests; Distinguish unit and integration checks; Test a program that reads and summarises marks.

Concepts: Parameterised tests; Isolation and fixtures; Testing an integrated program; Coverage and final review.

Class exercise: Design tests for a marks-file summary: normal data, one mark, threshold 50, empty file, malformed token and out-of-range mark.

After-class practice: Prepare a small marks-analysis project with methods, arrays, file I/O and a documented test suite. Use the companion project as a starting point.
